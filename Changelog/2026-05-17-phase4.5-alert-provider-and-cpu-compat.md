# 2026-05-17 Phase 4.5 Alert Provider And CPU Compatibility

## Summary

本轮完成 CPU 真实字段兼容修复，以及默认巡检告警源语义校正。

## Changes

- `app/monitoring/monitor_provider.py`
  - 修复 CPU summary 字段兼容：
    - `cpu_percent -> usage_percent`
    - `logical_cpu_count -> cores / logical_cpu_count`
    - `load_1m / load_5m / load_15m -> load_1 / load_5 / load_15`
- `app/monitoring/alert_provider.py`
  - 新增巡检告警来源抽象
  - 支持 `mock / remote_host / disabled`
  - `remote_host` 下按主机实时摘要合成：
    - `HostHighCPUUsage`
    - `HostHighMemoryUsage`
    - `HostHighDiskUsage`
- `mcp_servers/monitor_server.py`
  - 新增 `get_patrol_alerts`
  - 默认巡检可优先使用新的 alert provider 结果
- `app/agent/aiops/investigation/patrol_dispatch.py`
  - 支持主机级 `HostHighCPUUsage / HostHighMemoryUsage / HostHighDiskUsage`
- `app/agent/aiops/planner.py`
  - 默认巡检优先使用 `get_patrol_alerts`
  - 支持 `disabled` 告警源的受控收口
- `app/services/aiops_service.py`
  - 新增 `patrol_dispatch_disabled` 收口路径
- `.env`
  - 新增 `AIOPS_ALERT_PROVIDER`
- `tests/test_monitor_provider.py`
  - 新增 CPU 两种字段风格兼容测试
- `tests/test_alert_provider.py`
  - 新增 alert provider 三种模式的最小测试
